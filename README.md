# GESTOR-DE-TRAFEGO

Este repositório contém o **TrafegoAI** — um gestor de tráfego pago (Google, Meta e
TikTok) com IA e uma máquina de inteligência de tendências.

➡️ O projeto está na pasta [`trafegoai/`](./trafegoai). Veja o
[README completo](./trafegoai/README.md) para setup, arquitetura e deploy.

## Início rápido (modo demonstração, sem backend)

```bash
cd trafegoai/apps/web
npm install
NEXT_PUBLIC_DEMO_MODE=true npm run dev   # http://localhost:3000
```

Login demo: **demo@trafegoai.com / demo1234**.

## Stack completa

```bash
cd trafegoai
docker compose up
```
